## Workstream B — Bug Sweep (13 items found in the v3.1.4 full read)

- B1: **Honesty:** audio lane badges say "MP3" but no ffmpeg exists on-device → always M4A. Relabel "Audio Track (M4A)".
- B2: Merge progress order: 98% "Saving…" fires before 96% "Merging…" (plugin L1010 vs L1020) → reorder.
- B3: `copyToGallery` unconditional `source.delete()` + hardcoded "Gallery / Movies" return even on total failure (L1381) → honest result + correct destination label.
- B4: Cancel during gallery-save leaves the file in gallery while UI says "cancelled" (L1045) → cancel-check + orphan delete.
- B5: Delete-request results (reqCodes 10291/10292) never reported back → wire result callbacks so Vault reflects reality.
- B6: `cleanDir` non-recursive vs recursive `deleteTree` → unify (subdirs leak on cancel).
- B7: Job IDs = timestamp + `random()*1000` → UUID (collision class under rapid grabs).
- B8: `installApk` rejects on unknown-sources → open `ACTION_MANAGE_UNKNOWN_APP_SOURCES` instead of a dead-end error.
- B9: `shareExecutor` never shut down in `DowniDownloadService.onDestroy`.
- B10: Silent boot update check auto-opens the update sheet (L2620 runs even when `silent`) → silent stays silent; show a subtle "Update available" chip on the Settings card instead.
- B11: Cancel detection by error-message substring `'cancel'` (download + update paths) → explicit native error codes.
- B12: Dead code: `downloadManager` field, unused `HashSet/Set` imports, `cancelledPending` Set, `playlistGen`, self-described dead `p.failed` branch → remove.
- B13: `downloader.py`: duplicate selector in split video format string (L157–158); newest-file fallback scan (L687–694) restricted to the job's own expected names.

Each item = one card with exact change + risk note. UI polish (A3) must not alter engine behavior; bug-sweep diffs stay separate from polish diffs.

## Rules (unchanged)

- No client spoofing, no cookies/sessions, no `applicationId`/signing change, certifi stays simple.
- Any extraction-layer change → full device matrix before release (READ_THIS_BEFORE_UPGRADE).
- 100% vanilla JS, no new dependencies. ffmpeg stays out (no real MP3 — hence B1 relabel).
- **New git rule:** every version that gets a versionCode bump gets committed, tagged, and pushed the same day. No more uncommitted releases.
- **Scope law:** no Pause/Resume code, no TikTok photo code in any v3.2.0 commit.
